# 许可证适用范围

本仓库采用“按内容归属分别授权”的方式：

- 根目录 [`LICENSE`](../LICENSE) 的 MIT 条款仅适用于范展鹏有权授权的项目专用 ROS 配置、验证脚本和新写文档。
- [`firmware/ROSArduinoBridge4wd/`](../firmware/ROSArduinoBridge4wd) 是 ROSArduinoBridge 的修改版，保留 Patrick Goebel 等上游作者的 BSD 版权和免责声明，见 [`THIRD_PARTY_LICENSE_BSD.txt`](../firmware/THIRD_PARTY_LICENSE_BSD.txt)。根 MIT 许可证不覆盖或替换该 BSD 声明。
- [`assets/figures/`](../assets/figures) 中的本科论文照片、图表、接线图和实验截图用于项目说明与作品集展示，不自动按 MIT 许可再授权。
- GMapping、AMCL、Move Base、`rplidar_ros`、`usb_cam`、`ros_arduino_python` 等外部组件未整包复制进仓库，使用者须遵守其各自许可证。

英文摘要和相同边界见根目录 [`NOTICE`](../NOTICE)。
