## 2. Arduino PID 版本的证据

两份源代码的关键差异记录于 `PID_WORKSPACE_DIFF.patch`：

| 材料 | `doPID()` 状态 | 额外 `Serial.println(input)` |
| --- | --- | --- |
| 单独 `ros_arduino_bridge/` 固件 | 左、右、左后、右后共四路启用 | 注释 |
| `bishe/src/ros_arduino_bridge/` 固件 | 仅左轮一路启用 | 开启 |
| 用户本科论文《范展鹏毕业论文.docx》附录 C | 四路均启用 | 注释 |

因此，**论文的源代码附录更接近独立顶层副本，本仓库沿用这份作为归档候选**。但论文中的粘贴文本不等于历史烧录记录：材料没有可验证的 `.hex/.elf` 固件映像、上传日志或设备闪存转储。不能断言最终实机烧录了哪一份。

## 3. 文档反映的实操条件

- 论文第5章说明通过ROS Arduino桥接下发 `/cmd_vel`、返回编码器数据，上位机串口例子为 `/dev/ttyACM0`，波特率57600。
- 实际归档YAML（见 `ros_ws/src/car_start/config/arduino_params.yaml`）却配置 `port: /dev/ttyUSB0`。**该差异需要按实际串口设备核对，不能擅自修改成固定唯一端口**。
- 论文明确：结构方案设计的是履带式移动机器人，但为布线方便，导航与下位机控制实景实验改在**独立四轮全向轮实验平台**上进行。
- 原文声明使用杜邦线连接模块，没有独立生产PCB。上传的PDF是接线示意图，不等同于实际自研PCB版图或生产验证。
